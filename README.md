Project Description

This is a console-based Hospital Patient Admission System developed as part of a Programming 1B assignment. The system helps administrative staff manage patient records and hospital bed allocations more efficiently.

The system currently handles patient registration, search, update, delete, and display of patient records.

Features Implemented (Part 1)

1. Patient Management
- Register a new patient
- Search for a patient using their Patient ID
- Update an existing patient's details
- Delete a patient
- Display all registered patients

2. Patient Categories
Patients are categorised using an enum:
- INPATIENT
- OUTPATIENT
- EMERGENCY

3. Information Hiding
- Patient fields are private
- Access is controlled through getters and setter
